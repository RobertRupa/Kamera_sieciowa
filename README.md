# ESP32 My Project Guidelines

Reusable engineering standards for ESP-IDF C/C++ applications, VS Code and autonomous coding agents.

> This repository is being initialized with a modular, reviewable guidelines set. The canonical instructions will live in `AGENTS.md` and `docs/`.

## Scope
ESP32 family applications, modern ESP-IDF, object-oriented C++, MVC/ports-and-adapters, service contracts, Wi-Fi provisioning, encrypted NVS, mDNS, WebGUI, LVGL, and lean developer firmware workflows.

## Licensing and usage
Adopt the guidelines per hardware target, memory budget and device security profile. They are documentation, not a compiled firmware project.
